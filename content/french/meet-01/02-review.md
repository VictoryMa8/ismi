# Exchange names with a friend

Unreviewed private F25 draft · french-meet-01-02 · No publication approval, rights acceptance or model audio.

A mutual friend has explicitly invited Alex and Camille to use tu with each other.

Goal: Give an assigned name, ask a name and return the question.

## Dialogue

- **Alex:** Bonjour. · Hello.
- **Camille:** Bonjour. · Hello.
- **Alex:** Tu t’appelles comment ? · What is your name? (familiar)
- **Camille:** Je m’appelle Camille. · My name is Camille.
- **Camille:** Et toi ? · And you? (familiar)
- **Alex:** Je m’appelle Alex. · My name is Alex.

## Teaching and spelling help

### Ask a familiar person’s name

Tu t’appelles comment ? · What is your name? (familiar)

This is the familiar singular question used in the agreed tu setting. Keep t’ attached to appelles in the written phrase.

Recall before reveal: Ask for a name in the familiar setting.

### Give the assigned name Camille

Je m’appelle Camille. · My name is Camille.

Use the assigned name Camille. The phrase does not specify a gender.

Recall before reveal: Introduce yourself as Camille.

### Give the assigned name Alex

Je m’appelle Alex. · My name is Alex.

Keep m’ with appelle. Alex is an assigned fictional role, not a request for your real name.

Recall before reveal: Introduce yourself as Alex.

### Return a familiar question

Et toi ? · And you? (familiar)

After giving a name, this returns that same question to the familiar conversation partner. The preceding context supplies the topic.

Recall before reveal: Return the name question to a familiar friend.
