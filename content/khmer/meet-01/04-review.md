# Ask for help understanding

Unreviewed F26 candidate · khmer-meet-01-04 · text-only development-preview exception authorized separately; no linguistic approval or model audio.

In a noisy room you miss Sam’s name. Ask for help, read the repeated line, then respond. No listening is required in this text candidate.

Goal: Ask for repetition or slower speech, then respond.

## Dialogue

- **Sam:** ខ្ញុំឈ្មោះ Sam។ · khnhom chhmoh Sam · My name is Sam.
- **Alex:** សូមនិយាយម្តងទៀត។ · som niyeay mdong tiet · Please say it again.
- **Sam:** ខ្ញុំឈ្មោះ Sam។ · khnhom chhmoh Sam · My name is Sam.
- **Alex:** សូមនិយាយយឺតៗ។ · som niyeay yeut yeut · Please speak slowly.
- **Sam:** ខ្ញុំឈ្មោះ Sam។ · khnhom chhmoh Sam · My name is Sam.
- **Alex:** អរគុណ · aw-kun · Thank you.

## Teaching and optional script inventory

### Ask to hear it again

សូមនិយាយម្តងទៀត។

som niyeay mdong tiet · Please say it again.

Use the repetition request when you missed the words. It is distinct from a request to change speed. The script/help is an original modern candidate informed by a historical pattern, pending fluent review.

Recall: You missed a name. Ask the person to say it again.

### Ask for a slower exchange

សូមនិយាយយឺតៗ។

som niyeay yeut yeut · Please speak slowly.

Use the speed request when the words came too quickly. This modern script/help candidate needs fluent review; the historical reference does not approve it.

Recall: You heard the words but the pace was too fast. Ask for slower speech.

### Thank someone

អរគុណ

aw-kun · Thank you.

Use this after someone helps you. It acknowledges help rather than asking for new information.

Recall: Someone repeats their name for you. Thank them.
