## Owner decisions and boundaries

with a Metropolitan France reference, labeled regional alternatives when supported,
twelve units with five new lessons per unit, and a thirty-day target of a guided
five-minute conversation about introductions, family, food and plans at fifteen
minutes per day devoted to French. This replaces the previous proposed three-minute
month-one interaction target. It is an assessment target, not proven attainment,
a fluency promise or an outcome for a shared fifteen-minute multi-course budget.
English instruction, adult beginner/false-beginner entry and the free learning floor
remain unchanged. Use the twelve scenario briefs in the
[course contract](../planning/feature-scope-reference.md#f25-french-course).

Prepare unpublished drafts now; designate a fluent French reviewer before
publication. No reviewer has been designated. Implementation does not approve exact
wording, source rights, publishing, deployment, spending, hiring, contacting speakers,
a provider choice or beta inclusion. F28's alphabet approval is not used as course
approval; F30 still owns that pack's acceptance/release.

## First-unit candidate and implemented flow

[Five private packages](../../content/french/meet-01/README.md) cover opening/closing
a meeting, exchanging names with familiar address, meeting politely, asking for
clarification and applying these in a changed role. They contain 28 dialogue turns,
19 teaching cards and 30 contextual practice steps. Time estimates are unmeasured.
Alex and Camille are fictional roles. Fattoush and Knafeh remain learning guides;
no new character speaker mapping is invented.

The builder emits neutral schema-v2 fields, exact authored reconstruction segments,
contextual answer rationales, vocabulary tied to teaching cards, optional spelling
help, readable review sheets and SHA-256 package pins. No phonetic help is invented:
`helpConvention: none`, empty pronunciation-help fields and null audio are explicit.
The spelling disclosure says **Show meaning** when no pronunciation help exists.
Existing Arabic/Khmer pronunciation-help disclosures retain their labels.

The existing F24/F26 flow already supports French:

1. Whole-batch structural validation precedes transactional, idempotent private import.
2. Owner-only readiness reports separate draft and publication results.
3. The curriculum console previews pending-review text and exposes the blockers.
4. Approval/publication require actual linguistic review, cleared rights and resolved
   critical issues. The subsequently authorized exact five-preview exception is documented separately; normal approval retains the full gates.
5. An already loaded preview can run offline, but creates no downloaded package,
   learner completion or pending synchronization entry.

Course selection, separate progress, study allocation, review, glossary and eligible
unit checkpoints reuse the delivered foundation. Public availability is unchanged.
Starting-check calibration and sound modules are unfinished: use accepted published
content in the existing skippable, course-specific check later. Typed French recall
remains disabled pending a reviewed evaluator; exact display/tile strings are not
silently normalized. The manifest proposes samples, recording scripts, speaking
branch briefs, transfer tasks and the eleven remaining unit targets. Those briefs
are not implemented audio, automated feedback or a completed pilot.

## Recording, placement and pilot protocol

Use the pinned manifest's fourteen phrase scripts only after exact text acceptance.
Arrange permitted human recordings with speaker credit/consent, reference variety,
exact transcript/version and playback/offline rights. Do not substitute device
speech for human model evidence. A provider/privacy decision is required before
live AI feedback: minimum data, no provider training and prompt raw-recording deletion.
Uncertain natural alternatives route to review instead of authoritative rejection.

The first-unit pilot precedes bulk units 2–12. Agree participant/device setup with
the owner; no participant is contacted by this task. F18.1 remains deferred.

| Task | Evidence to record | Limit |
| --- | --- | --- |
| Familiar introduction | Assigned role/name, appropriate question, help and independent turns in a short guided exchange | First-unit task, not the five-minute month-one outcome |
| Polite introduction | Keep the explicitly selected singular vous setting; accept reviewed natural alternatives | Do not infer register from appearance or age alone |
| Repair | Signal missed meaning, request repetition or slower speech as needed, respond after clarification | Record intelligibility separately from accent similarity |
| Listening | Extract agreed details from exact reviewed human recordings | No listening result from written choices |
| Spelling/input | Real accented input, apostrophes, selection and exact tiles on supported mobile/desktop devices | No unrestricted spelling/reading score |
| Delayed transfer | Different assigned name and scene after at least 24 hours; record delay, help, exposure and attempts | Exact new prompts/answers need review before observation |
| Mixed study | Switch Arabic → French → Arabic; resume each started lesson with primary allocation preserved | Use accepted internal pilot content; do not publish a fixture |
| Accessibility/offline | Real keyboard, screen reader, text scaling, no-listening alternatives, downloads/reload/reconnect on supported browsers including Safari | Chromium automation is not physical-device/AT/Safari evidence |

Store private observations outside Git; use the
[evidence template](pilot-evidence.template.json) for aggregate results. Resolve
critical issues and retest before scaling the 55 remaining lessons. The month-one
rubric should separately report conversation duration/completed intents, requested
facts in a reviewed 45–60-second studied-topic dialogue, and a short invitation/reply.
Record denominators and help; no unobserved success or proficiency level is inferred.
